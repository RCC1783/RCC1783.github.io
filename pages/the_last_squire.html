Overview

The Last Squire is an arcade inspired game made for the 2026 Summer Summit Game Jame. The game was designed to be playable either by yourself or with a friend using a keyboard and mouse.

You can find the game at its itch.io page here

Roles: Programming

Timeline: ~3 Days

Tools: Unity 3D, Unity DevOps

Collaborators: Nadine Elkabir, Eshan Esmail, McKenzie Parkhurst

Goal:
Develop a prototype for a small, two player game in under three days that focuses on a few simple but unique core mechanic(s).
